# Simple Web Calculator

A clean, responsive web-based calculator. This project demonstrates basic DOM manipulation, CSS grid layouts, and mathematical evaluation using JavaScript.

**Key Features**
* Addition, subtraction, multiplication, and division operations.
* Clear (C) button to instantly reset the display.
* Responsive, modern design using CSS Grid for perfect button alignment.
* Basic error handling for invalid mathematical expressions.

**Technologies Used**
* **HTML5:** For structuring the display and keypad.
* **CSS3:** For styling, hover effects, and layout.
* **JavaScript:** For calculator logic and updating the interface.
